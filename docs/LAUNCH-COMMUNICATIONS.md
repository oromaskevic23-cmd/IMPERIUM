## Media / listing FAQ
**Is IMPERIUM already the digital currency used by AI agents worldwide?** No. That is a long-term architectural goal, not a current adoption claim.

**Is it a standalone blockchain?** No. The verified token contract is on Polygon mainnet.

**Does a public verified contract make it safe?** No. Source verification is not a security audit, nor does it establish the safety of surrounding systems.

**When will it list on an exchange?** There is no confirmed application, listing decision, or listing date in this repository. Exchange operators decide independently.

**What makes it different?** The proposed integration of AI Passport, independent work verification, Approval Gateway, Guardian Core, federated orchestrators and audit evidence into accountable agent settlement. Those integrations still require implementation and independent testing.

**Can holders expect guaranteed returns?** No. Crypto assets can lose all value, and no return is guaranteed.
