# Contributing
Contributions must be in English, attributable to verifiable evidence, and use narrow pull requests.

- Supply tests, implementation status, risk assessment and rollback notes.
- Never expose secrets or users' private information.
- Discuss architecture and payment controls before changing trust boundaries.
- No undocumented tokenomics changes, fabricated audits, fabricated exchange claims or financial promotion.
- Architect approval is required for material changes to the IMPERIAL Core architecture.
- Security concerns must follow [SECURITY.md](SECURITY.md).

Label every deliverable: **IMPLEMENTED / TESTED / BLOCKED / PROPOSED**.
