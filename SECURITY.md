# Security Policy

## Coordinated disclosure
Use **GitHub private vulnerability reporting / Security Advisories** when enabled. Never publish exploit instructions, API secrets, seed phrases, signing keys or security-sensitive logs in issues. If private reporting is unavailable, request a secure contact path from the repository owner without exposing exploit details.

## Required defense controls (proposed integrations)
Guardian Core, AI Passport, Enterprise Skills, Zero Trust, ProofGraph, Proof Passport, Approval Gateway, Audit Ledger, Owner Kill Switch, Public/Private Boundary and CRYPTO IMPERIAL Ecosystem Boundary.

No AI agent receives unrestricted spending credentials. Payments must be human-authorized unless separately approved bounded policies exist. Signing credentials must never be in agent memory or this repository.

Sourcify source verification is **not** an independent audit. No comprehensive security audit artifact is supplied here as of 2026-10-29. Tests, audits and incident plans are future evidence requirements; there is no claimed production settlement engine.
